## Changes
- The forced replacement selector now relies on the authenticated owning native forced request, source-current choice lease, and exact own-party eligibility. Removed two transient actor scheduling predicates (mustChoose/responses.empty) from *forced preparation* because an actively invoked current owning forced request can remain valid without those being set during the native replacement lifecycle. The independently selected switch must still be the unique current eligible own reserve and pass the final Cobblemon ShowdownActionResponse.isValid and promotion gates.
- The forced fallback now reports one of several REDACTED source readiness stages, enabling diagnosis without logging raw requests or opponent/private data. Lack of a proposal remains an emergency fallback, never a fabricated forced response.
- The independent Shadow engine has a minimum native-legal ordinary policy for a complete fresh owning request when the tactical scorer has no supported candidate (e.g. an unmodeled status move). This is *not* a claimed tactical value or guessed opponent effect. All actions still pass current native legal-root, gimmick and response validation before execution. Legacy stays only as the emergency recovery path.
- Expanded the source-bound Phase 6.16 spectator grammar to safely ignore known non-state public metadata and effect annotations while rejecting unknown/hidden request kinds; added narrowly recognized public event kinds already modeled by the independent Phase 4/6 filters.
- Extended the opponent projection across reused public active *positions* ONLY for a newly explicit current type witness. On such reuse, opponent stable identity and HP remain UNKNOWN; Illusion, Transform, form and unverified effects continue to abstain.
- Added standalone adversarial regression coverage for forced selection, source-only ordinary minimum actions, trapped/missing native choices, spectator type changes, Mega/annotation events, position reuse, and live integration wiring.
