   into `ShadowSearchEngine.Outcome` response probabilities.
2. Separately reviewed current-battle spectator/actor/turn public evidence and
   version-matched installed legal-action adapter still do not exist for
   Phase 5.21. Never join distinct appearance ordinals across Illusion/Transform.
3. Authorized real-replay held-out validation, calibrated opponent response
   forecasts, independent replay rights and external durable custody trust are
   unverified. Unapproved data must not be ingested.

   explicitly unknown branches, not all Cobblemon moves/abilities/items.
   Installed Cobbleverse gameplay, datapacks and actual Mixin behavior need
   controlled Minecraft validation before any deployment acceptance.

   observational, not an independently demonstrated native battle simulator.
   Final evaluation awaits Phase 6 and a separately approved real test plan.
